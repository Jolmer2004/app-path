Cómo funciona el enrutamiento en esta aplicación.

Path Location Strategy

El router usa la History API del navegador y genera rutas limpias como /about. Como GitHub Pages es hosting estático, se copia index.html como 404.html para que el acceso directo a una ruta cargue la aplicación y Angular la resuelva.

Ejemplo de ruta en esta app: /about
